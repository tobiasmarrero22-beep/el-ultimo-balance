# El Último Balance

Sistema de producción del canal de YouTube **El Último Balance**: historias de empresas que lo tuvieron todo… y lo perdieron.

| Carpeta | Qué hay |
|---|---|
| `videos/NNN-tema/` | Guion, imágenes, voz y `entrega/` con todo lo necesario para subir (SUBIR.md, miniaturas, subtítulos) |
| `pipeline/` | Scripts: investigación (API de YouTube), voz, imágenes, animación, miniaturas y metadatos |
| `canal/` | Logo, banner, marca de agua y descripción del canal |
| `datos/` | Investigación de nichos e ideas de vídeos con datos |
| `produccion.md` | Registro de vídeos producidos, subidos y créditos gastados |

Los vídeos `.mp4` no se guardan aquí (pesan demasiado): se entregan directamente en la conversación.
